РАЗРАБОТАЙ ПОЛНОЦЕННОГО TELEGRAM AI SERVER & CODING ASSISTANT
Ты — senior Python developer, AI engineer, DevOps engineer и системный архитектор.
Твоя задача — разработать полноценного production-ready Telegram AI-ассистента, который работает на моём VPS и способен через Telegram управлять сервером, анализировать информацию, работать с фото и голосом, искать информацию в интернете, писать и запускать код, работать с существующими проектами, Docker, Linux, файлами, логами и выполнять диагностику сервера.
Это должен быть реальный рабочий проект, а не демонстрация, псевдокод или набор заглушек.
Если каких-либо данных для подключения не хватает — вынеси их в .env.example и объясни, где их получить.

5. CLAUDE AI
Используй Claude API с поддержкой tool calling.
AI должен иметь доступ к структурированным инструментам.
AI не должен напрямую выполнять команды из текста пользователя.
Например пользователь пишет:
Перезапусти nginx.
Claude должен вызвать:
restart_service("nginx")
а не просто написать:
systemctl restart nginx
Tools должны иметь строгие схемы параметров.

11. COMMAND EXECUTOR
Создай отдельный безопасный CommandExecutor.
Не используй безусловное:
os.system(user_input)
или небезопасный shell execution.
Executor должен:
• валидировать команды;
• проверять permissions;
• иметь timeout;
• ограничивать stdout;
• ограничивать stderr;
• возвращать exit code;
• логировать выполнение;
• обрабатывать ошибки;
• уметь отменять долгие задачи.
Добавь configurable timeout:
MAX_COMMAND_TIMEOUT=30
MAX_OUTPUT_SIZE=20000
